# translate-vndb-description

VNDB 视觉小说简介中文翻译数据集——收录知名汉化 Galgame 的中文简介，与 VNDB 上的英文简介逐条对应。

## 数据说明

- **收录对象**：已存在汉化、且具备较高知名度的 Galgame（视觉小说）
- **简介来源**：[鲲galgame](https://www.kungal.com/) 站上已有的中文简介
- **收录原则**：只收录已有翻译的简介，没有已知翻译的游戏不写入

## 文件组织

- 每个 JSON 文件对应一个 VNDB 视觉小说编号（v）区间，**每 500 个 v 一个文件**
- 文件名为 6 位零填充数字，如 `000001.json` … `000122.json`
- 无条目的区间不生成文件，因此文件编号存在跳号
- 同一文件内条目按 v 编号升序排列

## 数据格式

每个文件是一个 JSON 数组：

```json
[
{
  "v" : "1",
  "translate" : "……中文简介正文……"
},
{
  "v" : "17",
  "translate" : "……中文简介正文……"
}
]
```

| 字段 | 说明 |
|------|------|
| `v` | VNDB 视觉小说编号（纯数字，不带 `v` 前缀） |
| `translate` | 对应游戏的中文简介正文 |

## 统计

- 88 个 JSON 文件
- 共 507 条简介（其中 `v1` 为仓库原有条目，内容保持字节一致）
